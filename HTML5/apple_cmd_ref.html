General commands
user$ chmod +x <\file\location\file.name> Add execute permission to a file.
user$ perl -pi -w -e 's|FIND_SOMETHING|REPLACE_WITH|g;' <where to search> Search and replace in files in the specified folder. This command is not recursive.
user$ find . -type f -iname '*.File suffix' -exec sed -i '' -e 's|FIND_SOMETHING|REPLACE_WITH|g' {} + Recursive search and replace. Run from the top-level folder you want to search.
user$ sudo fdesetup status Verify FileVault configuration.
user$ sudo discoveryutil mdnsflushcache Clear the DNS cache on older macOS versions (pre-Catalina).
user$ sudo killall -HUP mDNSResponder Clear the DNS cache on Catalina and later.
Screen commands
user$ ls ~/.screenrc Find the screen settings for Terminal.
user$ ls /dev/tty.* List USB and serial devices.
user$ screen -L /dev/tty.<name from above> <baud_rate> Connect to a serial device. Adding -L turns on output logging.
user$ screen -ls List active or detached screen sessions.
user$ screen -r Reconnect to the most recent screen session, or list sessions if multiple are active.
user$ screen /dev/tty.<name from above> <baud_rate> Open screen and set the baud rate.
After connecting to screen, use these commands:
Ctrl-A Ctrl-B Send a break command to the window.
Ctrl-A Ctrl-K Kill the current screen window.
Ctrl-A Ctrl-\ Quit screen and kill all windows.
Ctrl-A " Show active screen windows.
Ctrl-A A Rename the current window.
OpenSSL commands
user$ openssl req -noout -text -in <path to cert> Inspect a certificate signing request.
user$ openssl x509 -noout -text -in <path to cert> Inspect a certificate without installing it.
The .pem / .cer format might require an encoding option. You can drag a certificate into Terminal to insert its path.
user$ openssl x509 -inform pem -noout -text -in <path to cert>.cer Inspect a PEM-encoded certificate.
user$ openssl x509 -inform der -noout -text -in <path to cert>.cer Inspect a DER-encoded certificate.
You can also parse a CRL list to inspect serial numbers and revocation dates. A file starting with -----BEGIN X509 CRL----- is PEM; otherwise, it may be DER.
user$ openssl crl -inform pem -noout -text -in <path to cert>.crl Inspect a PEM-encoded certificate revocation list.
user$ openssl crl -inform der -noout -text -in <path to cert>.crl Inspect a DER-encoded certificate revocation list.
Validate file checksums and check transfer speeds
user$ shasum {-a 1 (default), 224, 256, 384, 512, 512224, 512256} <FULL_FILE_LOCATION> Calculate a file's SHA checksum.
user$ md5 <FULL_FILE_LOCATION> Calculate a file's MD5 hash.
user$ rsync -a --progress --stats --human-readable "source_file" "destination_location" Display transfer progress and statistics while sending a file.
* The remote volume must already be mounted in Finder for rsync to work.
Git command references
user/git_Folder$ git status Check the local repository status.
user/git_Folder$ git add <file_name> Stage a file for the next commit.
user/git_Folder$ git commit -m "some text to describe commit" Commit staged files.
user/git_Folder$ git log --oneline View Git history and commit points.
user/git_Folder$ git reset --hard <SHA1 Hash> Reset to a previous commit. This discards uncommitted changes.
user/git_Folder$ git push {-f} Push commits to the remote repository. Force-pushing can overwrite remote history.
Linux general command references
user$ getent passwd [userID]@[domain] Check directory-service account information and Unix POSIX attributes, if supported by your system.
user$ cat /etc/ssh/sshd_config Display SSH daemon configuration and access-related settings. Restart or reload sshd after making changes when required.
