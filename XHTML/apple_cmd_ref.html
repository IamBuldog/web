Commonly used Terminal.app commands
Search and replace (using find or perl), fdesetup, discoveryutil, screen, openssl, and other terminal.app commands
   https://developer.apple.com/library/mac/documentation/Darwin/Reference/ManPages/man1/screen.1.html
   https://developer.apple.com/library/mac/documentation/Darwin/Reference/ManPages/man1/rsync.1.html

General commands   
   user$ chmod +x <\file\location\file.name>  add execute attribute to any file
   user$ perl -pi -w -e 's|FIND_SOMETHING|REPLACE_WITH|g;' <where to search>  Can be run from anywhere but is NOT recursive. Only works on one Folder
   user$ find . -type f -iname '*.File suffix' -exec sed -i '' -e 's|FIND_SOMETHING|REPLACE_WITH|g' {} +  Recursive but must be run from top folder you want to search all sub-folders from
   user$ sudo fdesetup status  Used to verify FileVault configuration
   user$ sudo discoveryutil mdnsflushcache  Used to clear DNS Cache (Pre-Catalina)
   user$ sudo killall -HUP mDNSResponder  Used to clear DNS Cache (Catalina+)

Screen (Built in Termnal emulator) Commands		   
   user$ ls ~/.screenrc  To find the screen settings for terminal
   user$ ls /dev/tty.*  To see what USB / Serial devices you have
   user$ screen -L /dev/tty.<name from above> <baud_rate>  Adding -L turns on output logging
   user$ screen -ls  To lists any active / disattached screen sessions
   user$ screen -r  To reconnects to most recent screen session or lists sessions if multiple are active
   user$ screen /dev/tty.<name from above> <baud_rate>  Open screen and set Baud Rate
   After you're connected to screen, use the following comands to navigate   
    ^-a ^-b  Send break command to window
    ^-a ^-k  To kill the current screen and return to terminal window
    ^-a ^-\  To quit and kill all your ‘windows' and return to terminal window
    ^-a "  To show all active Screen sessions
    ^-a A  To change the name of the screen session

openSSL Commands		   
   user$ openssl req -noout -text -in <path to cert>  To validate a certificate signing request has the information you expected
   user$ openssl x509 -noout -text -in <path to cert>  To validate a certificate without installing it
   The format of the .pem / .cer file might require you specify encoding:  You can drag and drop certificate into Terminal for the <Path to cert>
    user$ openssl x509 -inform pem -noout -text -in <path to cert>.cer  To validate a PEM type certificate without installing it
    user$ openssl x509 -inform der -noout -text -in <path to cert>.cer  To validate a DER type certificate without installing it
   You can also parse the CRL list to see a list of Serial Numbers, revokation dates, etc.  Open CRL in text editor. If it starts -----BEGIN X509 CRL----- it's PEM, otherwise it's DER
    user$ openssl crl -inform pem -noout -text -in <path to cert>.crl  To validate a DER type certificate without installing it
    user$ openssl crl -inform der -noout -text -in <path to cert>.crl  To validate a DER type certificate without installing it

Validate File checksum and check transfer speeds 		  
   user$ shasum {-a 1 (default), 224, 256, 384, 512, 512224, 512256} <FULL_FILE_LOCATION>  To check SHA value of file
   user$ md5 <FULL_FILE_LOCATION>  To check MD5 has of file
   user$ rsync -a --progress --stats --human-readable "source_file" "destination_location"  To see transfer speed while sending a file
   *In order for rsync to work, remote volume must already be "mounted" in Finder   

GIT command references		   
   user/git_Folder$ git status  To check local repo versus master (remote) repo
   user/git_Folder$ git add <file_name>  To add / stage file to next commit
   user/git_Folder$ git commit -m "some text to describe commit"  To commit staged files to master repo
   user/git_Folder$ git log --oneline  To view git history and commit point
   user/git_Folder$ git reset --hard <SHA1 Hash>  To reset to a previous commit point
   user/git_Folder$ git push {-f}  To push commits (or resets) to master repo {use -f to force push if you used 'git reset'}
